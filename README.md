# Reuben — Builder Page

A personal Builder page created for the PIXL / The Hub **Building for Trial**.

## What this is

This is a hand-built personal portfolio site introducing Reuben as a Builder. It showcases projects, explains the way the site was built, and provides links for people who want to explore the work or get in touch.

The site deliberately uses plain web technologies rather than a framework:

- HTML5 for structure and content
- CSS3 for layout, responsive design, effects and visual identity
- A small amount of vanilla JavaScript for smooth in-page navigation

## Design

The visual direction is intentionally dark, technical and minimal. The page uses a near-black background, green builder accent, monospace technical details, grid lines, terminal-inspired UI and responsive cards.

The site includes:

- Responsive navigation
- Hero section
- Builder status terminal
- Project showcase
- Project technology tags
- About section
- Build-process section
- Contact section
- GitHub links
- Mobile layout
- Reduced-motion support
- Smooth in-page navigation

## Running locally

No build process is required.

Open `index.html` in a browser, or use a simple local server such as VS Code Live Server.

## Deployment

The site is designed to work directly with GitHub Pages because the repository contains a standard `index.html` entry point and has no server-side requirements.
