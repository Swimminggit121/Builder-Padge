ABOUT THE BUILDER

Curious by default.
Always making something.

I enjoy taking an idea that exists only as a thought and turning it into a working project. That means writing code, designing interfaces, debugging problems and repeatedly improving what I've made.

My projects jump between software, games and music because I like learning how different systems work. The common thread is simple: build it, test it, make it better, then ship it.

HOW I BUILD

Idea → build → iterate.

01

Start with an idea

Find something interesting and turn the idea into a clear goal.

02

Make a first version

Get a working prototype running instead of waiting for perfection.

03

Break things

Test the project, find the bugs and learn what needs changing.

04

Ship it

Polish the useful parts, document the work and put it in people's hands.
